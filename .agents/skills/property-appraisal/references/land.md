# Land / Plot Appraisal

Undeveloped or agricultural land is valued primarily via the **Sales Comparison Approach**, normalized per unit area (per sq ft, per acre, per guntha, etc. — use whatever unit is standard locally), plus consideration of **highest and best use**.

## Steps

1. **Confirm land use / zoning classification**: residential plot, agricultural, commercial/industrial, or mixed-use. Zoning drives value more than almost any other factor for raw land.

2. **Confirm development status**: is it a plotted/serviced plot (roads, utilities in place) or raw/unserviced land? Serviced plots command a significant premium.

3. **Select comparables**: recent land sales/listings of similar zoning, similar size, and similar accessibility in the same area. Land comparables are often scarcer than built-property comparables — search a wider radius or a longer time window if needed, and note the reduced confidence that results.

4. **Normalize and adjust** per unit area for:
   - Road access/frontage (corner plots and main-road frontage typically command a premium)
   - Shape and dimensions (irregular shapes are discounted)
   - Topography/soil (relevant for agricultural or construction feasibility)
   - Proximity to infrastructure (utilities, transit, development corridors)
   - Legal/title clarity — flag if this is unknown or unclear, since it materially affects marketability

5. **Consider highest and best use**: if the land's zoning or realistic near-term rezoning permits a more valuable use than its current one (e.g. agricultural land on the fringe of urban expansion), note this as a factor that could support a value above pure current-use comparables — but flag it as speculative/upside, not part of the base estimate.

## Notes

- For agricultural land, a secondary check is capitalized income from typical crop yield/lease rents in the area, though sales comparison usually dominates.
- Land values in fast-developing corridors can move quickly — prefer the most recent comparables available and note the sale date prominently.
