# Farm Appraisal

Covers Aura Estate's "farm" category — farmhouses and working/recreational farm properties, which blend residential and land valuation. Use a **combined approach**: value the residential improvements (house, outbuildings) via sales comparison, value the land/acreage separately, then combine — rather than treating the whole parcel as one undifferentiated unit.

## Steps

1. **Split the property into components**:
   - Residential structure(s): farmhouse, guest houses, staff quarters, barns/outbuildings — value using `residential.md` logic, adjusted for rural/semi-rural comparables rather than urban ones.
   - Land/acreage: value per-acre using nearby farm or large-plot land sales — see `land.md` for the land-side method.

2. **Identify use type**: recreational/lifestyle farm (weekend retreat, hobby farm) vs. working/productive farm (active agricultural income). This changes what drives value:
   - Recreational: driven by location desirability, house quality, views, privacy, proximity to a city/town.
   - Working farm: driven additionally by soil quality, water rights/irrigation, existing crop or livestock infrastructure, and historical yield/income if available.

3. **Find comparables** for both the improved (house) portion and the raw land portion separately where possible — combined farm-property comparables are often scarce, so triangulating from both sides improves confidence.

4. **Adjust for**:
   - Acreage and usable vs. unusable land (wetlands, steep terrain reduce usable acreage)
   - Water access/rights, irrigation infrastructure
   - Outbuildings and their condition (barns, stables, equipment sheds)
   - Fencing, existing agricultural infrastructure
   - Distance to nearest town/city (affects both lifestyle and working-farm value)
   - For a luxury marketplace like Aura Estate, also weigh privacy, views, and the quality/design of the main residence — these often dominate value on lifestyle-oriented farm listings.

5. **Reconcile**: sum the adjusted house value + adjusted land value, then sanity-check the total against any whole-farm-property comparables that exist, even if imperfect matches.

## Notes

- Working-farm income potential (crop/livestock revenue) can support a secondary income-approach cross-check, but for a luxury marketplace most farm listings will be lifestyle-driven — state which framing applies before valuing.
- Flag water rights and zoning/agricultural-use restrictions explicitly, since they can materially affect both value and what the land can legally be used for.
